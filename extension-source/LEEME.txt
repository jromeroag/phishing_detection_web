ESCUDO TRANSPARENTE v9.6.1
===========================

Esta versión ya está configurada para consultar el backend público del proyecto.
No necesitas ejecutar PowerShell, Python, Docker ni colocar claves API.

INSTALACIÓN EN GOOGLE CHROME
1. Descomprime el archivo ZIP.
2. Abre chrome://extensions en Chrome.
3. Activa "Modo de desarrollador".
4. Selecciona "Cargar extensión sin empaquetar".
5. Elige la carpeta que contiene manifest.json.

USO
- La extensión analiza automáticamente las páginas HTTP y HTTPS.
- Abre el icono del escudo para ver el resultado y sus evidencias.
- Verde significa que no se encontraron señales en las fuentes consultadas.
- Amarillo significa que se encontraron una o dos señales débiles. Puedes volver o continuar.
- Rojo significa que se encontró una señal fuerte o tres señales activas y se aplica el bloqueo preventivo.
- Un resultado no garantiza por sí solo que un sitio sea seguro o fraudulento.

PRIVACIDAD
- No incluyas claves API dentro de esta carpeta.
- La extensión no solicita ni almacena contraseñas.
- Las consultas de reputación se realizan mediante el backend del proyecto.

Si la consulta remota tarda, espera unos segundos y pulsa "Reintentar consulta".
